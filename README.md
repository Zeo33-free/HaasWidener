# HaasWidener

JUCE‑based stereo widener | Mono‑safe | Wet filters

- Expands stereo image without phase cancellation when summed to mono
- Low‑cut & high‑cut filters on wet signal only
- Simple control

https://www.bilibili.com/video/BV1aoRQBqE9F

Warning: Inserting any additional effects after this plugin may introduce phase issues when the signal is collapsed to mono.
